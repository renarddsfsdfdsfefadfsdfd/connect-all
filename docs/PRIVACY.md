# Connect All — 隐私模型

> 一句话：**消息和记忆是你们的；服务器只拿到看不懂的密文。**

这份文档不写营销口号，只列清楚「什么数据在哪儿、谁能看到、怎么删」。

## 1. 数据流一览

| 数据 | 存在哪里 | 谁能读 |
|---|---|---|
| 聊天原文 | 两台设备本地 `chat.jsonl` | 你和对方（设备持有人） |
| 聊天传输 | LAN TCP 或自建中继 | 仅两端；服务器只看到 AES-GCM 密文 |
| CI 记忆卡片 | 本机 `ci.jsonl` | 你（以及你主动开启的加密备份） |
| CI 发给模型的文本 | DeepSeek / 豆包 API | 对应模型供应商（见 §4） |
| 日历 ICS 原文 | 本机 `calendar/` | 你 |
| 共享给对方的事件 | 对方设备 `partner.json` | 仅标题/时间/地点/全天/PRIVATE 标记 |
| 状态（在线、地点文字、开机时间） | 本机 + 加密状态包 | 对方（可在设置关闭位置/开机时间） |
| API Key、配对根密钥 | 系统钥匙串（`secrets.json` 密文） | 本机 OS |
| 加密备份 | 你的服务器 + 本机 `backups/` | 只有持有配对密钥的设备 |
| 服务器日志 | 服务器 | 服务器管理员（你） |
| 使用统计 / 遥测 | **不存在** | — |

## 2. 服务器能看到什么

中继服务器（`server/`）只保存/转发：

- 由牵手码 HMAC 派生出的 **房间 ID**（不是 6 位码本身）
- 设备 ID、设备名、平台（客户端主动放在状态包外的连接参数）
- 每条密文的 **大小、时间戳、序号**
- 加密备份的 **文件名、大小**

它**不能**解密或读取：

- 消息、日历、状态、CI 记忆
- API Key（从未离开主进程，且只在访问模型时使用）
- 配对根密钥（只在设备钥匙串里）
- 屏幕/摄像头/麦克风内容（WebRTC 媒体不走中继）

### 元数据泄露

即使内容加密，服务器仍能推断「两台设备在某时段频繁通信」「某天备份变大」。这是任何中继都无法避免的元数据。要彻底消除，只能纯 P2P + 无备份。

## 3. 端到端加密细节

- X25519 ECDH 派生共享秘密；HKDF-SHA256 派生 root 与每类消息子密钥。
- AES-256-GCM，每条消息独立 12B IV；AAD 绑定消息类型（防止类型替换）。
- 8 位 SAS（`HMAC(root,'sas')` 取 6 字节）用于人类核对，抵御恶意服务器替换公钥。
- 6 位牵手码只用于房间寻址；不直接作为加密密钥（低熵）。
- 中继 token 由牵手码 HMAC 派生，服务器只存 SHA-256 哈希。

**边界**：如果攻击者同时控制你的服务器、并能在你们核对 SAS 时欺骗两个人，理论上可以 MITM。请务必在牵手时核对 8 位数字；不一致就是有人在中间。

## 4. 模型供应商

开启 Connect Intelligence 且填写 API Key 后：

- 聊天文本片段、可选的双方日程摘要、你填写的「附加要求」会发送到 **你自己选择的** DeepSeek 或豆包（Volcengine Ark）接口。
- 请求由主进程直接发往 `baseUrl`；不经过 Connect All 的任何服务器。
- API Key 存在系统钥匙串，渲染进程只能看到掩码（`sk-••••abcd`）。
- 供应商的日志/训练政策由供应商决定；如果介意，使用**不填 Key 的本地整理模式**，或自建 OpenAI 兼容网关并把接口地址指向它。
- 汇总结果只写本机，不会自动发给对方，也不会自动上传到中继。

## 5. 本地数据与删除

数据目录（见 README）里：

- **聊天**：设置 → 隐私与数据 → 清空本机聊天（仅本机；对方和服务器副本不受影响）。
- **CI 记忆**：清空 CI 记忆，或设置保留期（30/90/180/365 天/永久）。
- **日历**：逐个移除来源；对方快照可被下一次共享覆盖，也可清空应用数据目录。
- **备份**：本机 `backups/` 最近 6 份；服务器端在私有服务器窗口或服务器 `backups/<room>/` 删除。
- **解除牵手**：会删除本机 root 与 peer 记录；聊天/记忆仍保留（它们是本机历史）。旧备份从此无法解密——这是设计使然。

卸载应用不会自动清空数据目录；需要手动删除。

## 6. 权限

| 权限 | 何时请求 | 拒绝后果 |
|---|---|---|
| 摄像头 / 麦克风 | 发起或接听视频 | 可退化为仅共享屏幕/仅语音 |
| 屏幕录制 | 点「共享屏幕」 | 无法一起看电影 |
| 局域网 | 系统隐私提示（macOS） | 退化为服务器中继 |
| 通知 | 首次系统通知 | 无桌面提醒，应用内仍有 |

应用不申请通讯录、定位、剪贴板读取、辅助功能、全盘访问。位置文字完全由你输入或从日历 LOCATION 推导。

## 7. 威胁模型

| 威胁 | 缓解 |
|---|---|
| 服务器管理员偷看 | 端到端加密；服务器只有密文 |
| 恶意服务器替换公钥 | 8 位 SAS 人工核对 |
| 陌生人猜 6 位码 | 限流、15 分钟 TTL、最多 2 设备、SAS 校验 |
| 公共 Wi-Fi 抓包 | 消息本身加密；建议服务器用 TLS |
| 设备丢失 | 依赖系统登录密码/FileVault；可解除牵手使新消息无法解密（旧本地明文仍可能被读） |
| API Key 泄露 | 钥匙串加密；只在主进程使用；不上传 |
| 备份服务器被拖库 | 备份为 AES-GCM 密文，无 root 不可解 |
| 恶意日历 ICS | 纯解析，不执行脚本；限制大小/事件数；超长字段截断 |
| 恶意链接 | 只允许 http(s) 外链，且需用户点击；渲染进程 CSP `default-src 'self'` |
| XSS | 渲染进程无 Node、无 `innerHTML` 注入用户消息（文本节点渲染）、CSP 限制脚本 |

**不在防护范围**：已经拿到你解锁设备的人；键盘记录器；被篡改的系统钥匙串；你主动把聊天截图发给别人。

## 8. 遥测与第三方

- 没有分析 SDK、没有崩溃上报、没有广告、没有账号服务器。
- 外部请求只有三类：
  1. 你的私有中继（HTTP/WS）；
  2. 你选择的模型 API（仅 CI 开启且填 Key 时）；
  3. 可选 STUN/TURN（WebRTC；默认 `stun.l.google.com`，可在设置里换成自己的）。
- 想完全离线：传输模式选「离线」，CI 不填 Key，视频不使用。此时应用只读写本地。

## 9. 建议

1. 服务器一定上 TLS；不要把 8787 裸奔公网。
2. 牵手时**当面/语音核对 8 位数字**，不要只截图。
3. Mac 开 FileVault，Windows 开 BitLocker，Linux 用全盘加密。
4. 如果聊天极其敏感，定期清空本机聊天或缩短保留期；CI 记忆同理。
5. 不要把服务器 root 密码、API Key 写进任何聊天（即使加密，也仍会进入本地日志与模型上下文）。
